# Linux samples

## `sshd_live_capture.log`

The 18 sshd/PAM records produced by **9 failed SSH password attempts** (3 connections x 3 password
prompts, users `wcpt-alice`, `wcpt-bob`, `wcpt-carol`) during the live test of 2026-11-21, exactly
as indexed in `event.original` by Wazuh 5.0.0-rc1 (collected from journald by wazuh-agent
5.0.0-rc1 on Ubuntu 22.04.5, OpenSSH 8.9p1).

Per connection: one PAM `authentication failure`, three `Failed password` (the counted events),
`Connection closed ... [preauth]`, and `PAM 2 more authentication failures`.

Sanitization: none needed. `wcp-ep1` is a lab container, `10.231.40.118` a lab bridge address,
`wcpt-*` locked test accounts; no credentials appear in sshd logs.

Replay lines for the other scenarios are generated by `tests/lab/lab.py` in the same format
(`sshd_failed_line`, `sshd_attempt_lines`).
